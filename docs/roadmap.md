# Peloton Ridder — план реализации в реальный код

Стек: Next.js (App Router, TypeScript) + PostgreSQL + Prisma + Auth.js.
Меркант Kaspi Pay — есть/в процессе оформления.
Реализация — совместно с Claude Code.

Модель данных (черновая): `RaceSeries` (вечнозелёное описание трассы: Radon/UpHill/Panorama/Ski) →
`Event` (конкретное годовое издание: дата, статус, партнёры) → `Distance` (км, цена, cutoff) →
`Registration` (User + Distance + статус оплаты + номер) → `Result` (место, время).
Плюс `User`, `Season` — для зачёта Ridder Race Series.

Статусы: `todo` / `in progress` / `done` / `blocked`. При импорте в Notion удобно сделать
это отдельным полем-статусом у каждой карточки.
