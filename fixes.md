# Сделанные фиксы и фичи

## Деплой
- `deploy.sh` переписан: сборка локально на маке `--platform linux/amd64`, tar.gz копируется на сервер через scp, `docker load` на сервере
- NEXT_PUBLIC_* переменные берутся с сервера (не из локального .env)
- При деплое автоматически: `git pull` + `docker compose build migrate` + `prisma migrate deploy` → потом перезапуск app

---

## T122 — Результаты по дистанциям + поиск
- CSV-импорт результатов привязан к выбранной дистанции (удаляет/создаёт только по ней)
- Фильтр по дистанциям (пилюли) в таблице результатов в админке
- Поле поиска и фильтр по дистанциям на публичной странице забега
- Внешняя ссылка на сторонние результаты открывается рядом с фильтром

## T123 — Кликабельное «Место старта»
- Поле `locationUrl` в Event (миграция)
- Поле ввода в форме редактирования события
- Пилюля «на карте ↗» рядом с местом на публичной странице (открывает в новой вкладке)

## T124 — Сертификация трассы (ITRA и др.)
- Поля `certification` и `certificationPoints` в Distance (миграция)
- Поля ввода в форме дистанции
- Отображение «Сертифицировано ITRA · 45 баллов» в блоке дистанции на публичной странице

## T125 — Навигация по вкладкам страницы забега
- Стрелки ← → для прокрутки таб-бара (видны только при наличии скрытых вкладок)
- Свайп по контенту (порог 40px)
- Закруглённые углы у стрелок (matching card radius)

## T126 — Обложки для ссылок на фотоальбомы
- Тип `PhotoLink` расширен полем `coverUrl`
- В админке при добавлении ссылки можно загрузить обложку → MinIO bucket `photo-covers`
- На публичной странице ссылки отображаются карточками с превью (aspect-[4/3], hover-zoom)

## T127 — Фото события
- Загрузка нескольких фото события в MinIO bucket `event-photos`
- Сетка фотографий с лайтбоксом на публичной странице
- `eventPhotos Json?` в Event (миграция)

## T128 — URL «Как добраться»
- Поле `howToGetUrl` в Event (миграция)
- Поле ввода URL в секции «Как добраться» в админке
- Кнопка «Открыть на карте» с иконкой пина на публичной странице
- Вкладка «Как добраться» скрыта если нет ни текста ни ссылки

## T129 — Чекбоксы «Пакет» и «Посадка» в списке регистраций
- Колонка «Пакет» — inline-чекбокс, сохраняет `kitPickedUpAt` сразу при клике
- Колонка «Посадка» — inline-чекбокс для `transferUsedAt`, показывается только у участников с трансфером
- Оптимистичный UI: чекбокс переключается мгновенно, откатывается при ошибке
