# Тикеты улучшений (T108–T149) — Фаза «8. Улучшения»

## 🔴 Баги

### T108. Цена слота отображает стоимость трансфера
На странице оплаты слота показывается цена трансфера вместо цены самого слота.
Проверить и исправить логику расчёта суммы на странице checkout — цена слота и цена трансфера не должны подменять друг друга.

### T109. «Показать билет» после оплаты редиректит на оплату
После успешной оплаты нажатие на «Показать билет» возвращает пользователя обратно на страницу покупки.
Исправить redirect после подтверждения оплаты Kaspi — направлять на `/tickets/[id]`.

### T110. «+Трансфер» предлагает купить слот вместо добавления трансфера
При нажатии на кнопку «+Трансфер» (добавить трансфер к существующей регистрации) показывается предложение купить слот.
Исправить логику флоу — кнопка «+Трансфер» должна открывать оплату только трансфера, не слота.

### T111. Тренировочные группы не отображаются после создания
После создания тренировочной группы в `/admin/club/training-groups` группа не отображается в публичном разделе клуба.
Проверить запрос на публичной странице — убедиться что новые группы подтягиваются корректно.

### T112. Ошибка сервера при отправке письма волонтёру
При отправке письма волонтёру из панели администратора страница падает:
> "This page couldn't load. A server error occurred."
Найти источник ошибки в server action / SMTP, исправить. Добавить нормальную обработку ошибок для UI (toast, не падать).

### T113. GPX elevation profile исчезает у новых дистанций
При добавлении новой дистанции к забегу профиль высот (elevation profile) не отображается, даже если GPX файл привязан.
Проверить передачу `gpxUrl` для новых дистанций в компонент профиля высот.

### T114. Раздел «Снаряжение для забега» не работает
Раздел снаряжения/экипировки на странице забега сломан.
1. Починить отображение раздела.
2. Сделать редактируемым из админки: добавлять/убирать предметы с опцией **Обязательное** / **Рекомендованное**.

## 🏃 Регистрация

### T115. Валидация: только латиница в полях имя/фамилия
Поля «Имя» и «Фамилия» при регистрации на забег принимают только латинские символы (A–Z, a–z, дефис, пробел). Кириллица запрещена. Показывать понятную ошибку под полем.
**Причина:** имя/фамилия идёт в стартовый протокол ITRA и других международных систем, где требуется латиница.

### T116. Поле квалификации при регистрации на дистанцию
- В настройках дистанции: переключатель «Требуется квалификация».
- Если включён: при регистрации появляется обязательное поле — загрузить файл или вставить ссылку (результат забега, страховка и т.д.).
- Администратор видит загруженный файл в панели регистраций.

### T117. Waitlist: рассылка всем в очереди при освобождении слота
**Флоу:**
1. Бегун встаёт в очередь бесплатно когда слоты закончились.
2. Когда слот освобождается (бронь истекла или возврат): письмо всем в очереди одновременно.
3. Кто первый оплатил — тот получает слот.
4. Остальным: «Место занято».
**Технически:** нужен фоновый cron job для проверки истёкших броней.

## 💳 Оплата и билет

### T118. Промокод: скидка только на слот, не на трансфер; починка расчёта суммы
**Баги:**
1. Промокод вводится, но цена не пересчитывается.
2. Итоговая сумма (слот + трансфер) не складывается корректно.
**Бизнес-правило:** скидка промокода применяется **только к слоту**. Трансфер — всегда полная цена.

### T119. Частичный возврат — слот или трансфер
**Флоу:**
1. Бегун запрашивает возврат слота ИЛИ трансфера через личный кабинет.
2. Администратор получает уведомление (email/Telegram).
3. Администратор вручную возвращает деньги через Kaspi.
4. Администратор нажимает «Подтвердить возврат» в системе → статус обновляется.

### T120. Кнопки возврата скрываются после сканирования QR
**Логика на странице билета бегуна:**
- Если QR слота отсканирован (пакет выдан): кнопка «Вернуть слот» скрывается, «Вернуть трансфер» остаётся.
- Если QR трансфера активирован (посадка отмечена): кнопка «Вернуть трансфер» скрывается, возврат слота тоже невозможен.

## 💰 Финансы и отчёты

### T135. /admin/reports — расширение данных и терминология
- Добавить: общее кол-во регистраций, из них оплачено, из них бронь.
- Переименовать: «Скидки» → «Потерянная выгода».

### T136. Финансовый отчёт — расходы на медали/футболки, доп.расходы, спонсоры
1. **Медали/футболки:** ввод кол-ва единиц по дистанциям + цена за штуку → идёт в расходы.
2. **Доп. расходы:** произвольное текстовое поле + сумма.
3. **Доп. доходы:** спонсоры, гранты и т.д.
4. **Итог:** реальный доход = оплачено − расходы + доп. доходы.

## 👤 Роли и права

### T137. Роль «Оператор» — регистрация, выдача, трансфер
Новая роль, назначается администратором.
**Доступ:** регистрация бегунов, выдача наборов, посадка на трансфер.
**Нет доступа:** финансы, настройки, управление пользователями.

### T138. Роль «Фин-Админ» — доступ к финансам и отчётам
Новая роль, назначается супер-админом.
**Доступ:** `/admin/reports`, финансовые данные регистраций.
**Нет доступа:** управление пользователями, настройки сайта.

### T139. Супер-Админ через SUPER_ADMIN_EMAIL в .env
- Если email пользователя совпадает с `SUPER_ADMIN_EMAIL` в `.env` → автоматически супер-админ.
- Нельзя заблокировать или лишить прав через UI или API.
- Может: назначать роли (admin, fin-admin, operator) любому пользователю.
