# Peloton Ridder — новый сайт клуба

**Что это.** Редизайн сайта беговой федерации Peloton Ridder (г. Риддер, ВКО) — сейчас на стадии дизайн-прототипа, дальше переводим в реальный код (Next.js + база данных).

**Зачем.** Действующий сайт устарел морально и функционально. Новый сайт должен закрывать весь цикл: от знакомства с клубом и забегами до онлайн-регистрации с оплатой, личного кабинета участника и админ-панели для организаторов — без ручной рутины в вотсапе и экселе.

**Что входит по функционалу:**

- **Забеги клуба** — Radon Race, Ridder UpHill, Panorama Fall Run, Ski Summer Fest: календарь, архив прошлых сезонов, страница каждого забега (трасса, профиль высоты, карта, снаряжение, регламент)
- **Ridder Race Series** — три из четырёх забегов объединены в общий сезонный зачёт, с зачётной таблицей и архивом сезонов
- **Регистрация и оплата** — онлайн-регистрация на забег с оплатой через Kaspi Pay, автоматическое присвоение стартового номера
- **Личный кабинет участника** — история стартов, статус регистрации, прогресс в серии
- **Волонтёрство** — заявка на волонтёрство прямо на сайте, рассмотрение админом
- **Мультиязычность** — русский, казахский, английский, китайский
- **Админ-панель для организаторов** — создание и ведение забегов, список участников, загрузка результатов, управление партнёрами, рассылки, лист ожидания на заполненные дистанции

**Статус.** Дизайн и логика проработаны и провалидированы на прототипе, сейчас в работе — перенос в реальный продакшен-код с базой данных.
